## Цель

По [условию задачи](condition.txt) даны два пустых бидона на 7 и 5 литров. Нужно получить ровно 4 литра в 7-литровом бидоне. Количество воды во втором бидоне не важно.

## Модель и алгоритм

Состояние `(x, y)` — количество воды в 7-литровом и 5-литровом бидонах соответственно. Начальное состояние — `(0, 0)`, цель — любое состояние с `x = 4`.

- Наполнение заменяет объём в выбранном бидоне его вместимостью, опустошение — нулём.
- При переливании переносится минимум из объёма воды в источнике и свободного места в приёмнике. Например, из 7-литрового в 5-литровый переносится `min(x, 5 − y)` литров.
- Действия, не меняющие состояние, не рассматриваются.

В [программе](main.py) поиск в ширину (BFS) перебирает состояния в порядке увеличения числа действий. При первом посещении состояния сохраняются предыдущее состояние и действие, которым оно получено. После достижения цели эти записи используются для восстановления пути.

## Решение

| № | Действие | 7-литровый (л) | 5-литровый (л) |
| ---: | --- | ---: | ---: |
| 0 | Оба бидона пусты | 0 | 0 |
| 1 | Наполнить 7-литровый бидон | 7 | 0 |
| 2 | Перелить 5 л из 7-литрового в 5-литровый до заполнения второго | 2 | 5 |
| 3 | Опустошить 5-литровый бидон | 2 | 0 |
| 4 | Перелить оставшиеся 2 л из 7-литрового в 5-литровый | 0 | 2 |
| 5 | Снова наполнить 7-литровый бидон | 7 | 2 |
| 6 | Перелить 3 л из 7-литрового в 5-литровый до заполнения второго | **4** | 5 |

### Почему шесть действий — минимум

В таблице указаны состояния, которые впервые достижимы за соответствующее число действий. Каждый следующий слой получается применением всех допустимых действий к предыдущему слою и исключением уже посещённых состояний.

| Число действий | Новые состояния `(x, y)` |
| ---: | --- |
| 0 | `(0, 0)` |
| 1 | `(0, 5)`, `(7, 0)` |
| 2 | `(2, 5)`, `(5, 0)`, `(7, 5)` |
| 3 | `(2, 0)`, `(5, 5)` |
| 4 | `(0, 2)`, `(7, 3)` |
| 5 | `(0, 3)`, `(7, 2)` |
| 6 | `(3, 0)`, **`(4, 5)`** |

Ни в одном из слоёв от 0 до 5 нет состояния с `x = 4`. Значит, получить нужный объём раньше шестого действия невозможно.

## Запуск и проверка

Из папки `individual`, используя Python 3 без сторонних библиотек:

```console
python main.py
python -m unittest -v
```

Программа вывела путь из шести действий до состояния `(4, 5)`. Все четыре [автоматических теста](test_main.py) прошли: проверены действия из начального состояния, правила переливания, найденная последовательность и отсутствие цели после пяти или меньшего числа действий.

## Вывод

Ровно 4 литра в 7-литровом бидоне получены за минимальные **6 действий**. В 5-литровом бидоне к этому моменту остаётся 5 литров, что допускается условием.
