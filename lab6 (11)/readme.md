## Цель

Распознать язык грамматики из [задания 8](condition.txt): непустые строки из латинских строчных букв `a` чётной длины.

## Реализация

Функция `recognize` в [main.py](main.py) отклоняет пустую строку и строки нечётной длины. Затем она проверяет строку по непересекающимся парам символов: каждая пара должна быть `aa`. Пробелы и другие символы не удаляются и приводят к отклонению.

Правило `S → aaS` соответствует проверке очередной пары перед последней, а `S → aa` — проверке последней пары. Поэтому любая принятая строка выводится из грамматики: для `j` пар достаточно `j − 1` применений рекурсивного правила и одного применения базового. И наоборот, любая выведенная строка состоит из одной или нескольких пар `aa` и проходит проверку. Для строки длины `n` проверка занимает `O(n)` времени и `O(1)` дополнительной памяти.

## Запуск и проверка

Команды выполняются из папки лабораторной. Нужен Python 3, сторонних библиотек нет.

```console
python main.py aaaa
Принята
python main.py aaa
Отклонена
python main.py aabbaa
Отклонена
```

Для запуска [тестов](test_main.py):

```console
python -m unittest -v
```

Все 4 теста прошли. Они охватывают 14 входных строк: допустимые цепочки (включая 10 000 букв), пустую строку, нечётные длины, посторонние символы, пробел, перевод строки и кириллическую `а`.

## Вывод

Распознаватель принимает ровно строки вида `a^(2j)` при `j ≥ 1`.
