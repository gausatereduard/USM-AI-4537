## Цель

С помощью генетического алгоритма переставить числа от 1 до 10 так, чтобы большие числа находились ближе к краям, а маленькие — ближе к центру. [Исходное условие](condition.txt).

## Критерий качества

Хромосома — перестановка чисел от 1 до 10. Позициям присваиваются симметричные веса `4 3 2 1 0 0 1 2 3 4`. Оценка `F` — сумма произведений числа на вес его позиции. Чем больше `F`, тем лучше распределение. Позиции на одинаковом расстоянии от центра имеют одинаковый вес, поэтому оба примера из условия получают одинаковую оценку.

Если число `x` стоит на позиции с весом `p`, а большее число `y` — на позиции с меньшим весом `q`, их обмен увеличивает оценку на `(y − x)(p − q) > 0`. Поэтому в оптимуме на краях стоят числа 9 и 10, затем 7 и 8, 5 и 6, 3 и 4, а в центре — 1 и 2. Порядок внутри каждой пары не важен. Максимальная оценка равна `4 × (9 + 10) + 3 × (7 + 8) + 2 × (5 + 6) + (3 + 4) = 150`.

## Алгоритм

1. Создаются 60 случайных перестановок (поколение 0).
2. Для выбора каждого родителя из трёх случайных особей берётся та, у которой самая высокая оценка (турнирный отбор).
3. При скрещивании OX потомок получает случайный отрезок первого родителя. Остальные позиции заполняются числами второго родителя в циклическом порядке, начиная после скопированного отрезка и пропуская уже использованные числа.
4. С вероятностью 25% у потомка меняются местами два случайных числа. Лучшая особь переносится в следующее поколение без изменений, поэтому лучшая оценка не падает.
5. Поиск завершается при достижении оценки 150 либо после 200 поколений. Максимум используется только для остановки: начальная популяция не содержит специально добавленного решения. Если максимум не достигнут, программа показывает лучший найденный результат.

## Результат и проверка

При `seed = 42` начальная лучшая оценка составила 138, а на 18-м поколении программа получила **150 из 150**:

```text
9 7 6 4 1 2 3 5 8 10
```

В дополнительных 100 запусках с начальными значениями генератора от 0 до 99 максимум достигнут во всех случаях, за 3–38 поколений. Это результат эксперимента, а не гарантия сходимости при любом запуске.

[Автоматические тесты](test_main.py) проверяют оценку двух примеров из условия и обратного распределения, сохранение перестановок при скрещивании и мутации, достижение максимума и воспроизводимость запуска с `seed = 42`.

Для запуска из папки работы нужен Python 3, сторонних библиотек нет:

```console
python main.py --seed 42
python -m unittest -v
```
